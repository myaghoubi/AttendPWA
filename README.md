# حضور و غیاب (PWA) — مرحلهٔ ۱

## بارگذاری در GitHub Pages
1. یک مخزن (repo) جدید در GitHub بسازید (مثلاً `attendance-pwa`).
2. همهٔ فایل‌های این پوشه را (نه خود پوشه را) در ریشهٔ مخزن آپلود کنید:
   `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/`
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` و پوشهٔ `/ (root)` ← Save.
4. بعد از یکی دو دقیقه آدرس `https://<نام‌کاربری>.github.io/<نام‌مخزن>/` فعال می‌شود.
5. در گوشی آن را باز کنید و نصب کنید:
   - اندروید (Chrome): منو ← Install app
   - آیفون (Safari): دکمهٔ اشتراک‌گذاری ← Add to Home Screen

## به‌روزرسانی
بعد از تغییر هر فایل، عدد `VERSION` را در `sw.js` بالا ببرید (`v2`, `v3`, …) تا گوشی‌ها نسخهٔ جدید را بگیرند.

## وضعیت
- دروس (افزودن، تغییر نام، حذف با «برگردان»)
- تعریف افراد برای هر درس
- تنظیمات: تم، پشتیبان‌گیری و بازیابی، راهنمای نصب
- کار آفلاین
- حضور و غیاب با دوربین و سوابق حضور: مراحل بعد
